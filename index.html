02 授業・チーム開発

Javaモン

授業のチーム開発で制作した、ポケモン風のターン制バトルゲーム。 5属性の相性、状態異常、アイテム、メガシンカを実装し、 Java Swing で画面を作って BGM も再生します。

担当
チーム開発・リーダー（プロジェクト進行）
規模
Java 約760行
工夫した点
BGM再生を抽象クラス Player と継承クラスに分離し、属性と状態異常は enum で型として定義。ダメージ計算はタイプ相性と乱数を含めて専用クラスに集約しました

  • Swing
